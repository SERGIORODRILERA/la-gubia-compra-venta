# La Gubía · Compra-venta de caballos

Presentación animada de la propuesta para Club Hípico La Gubía.

- Abre `index.html` en un navegador (necesita conexión para las tipografías).
- Pensada para iPad en horizontal: desliza para pasar de diapositiva.
- Los caballos, precios y resultados de las maquetas son datos de ejemplo.
